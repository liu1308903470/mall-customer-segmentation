# Data Dictionary
| Field Name | Type | Description |
|------------|------|-------------|
| CustomerID | string | Unique customer ID |
| Annual_Income | int | Customer annual income, in RMB |
| Total_Spend | int | Cumulative customer spending, in RMB |
| Purchase_Frequency | int | Annual purchase frequency |
| Average_Order_Value | int | Average order value, in RMB |
| Age | int | Customer age |
| Cluster | int | Clustering segmentation label (0-4) |
| CLV | float | Customer lifetime value |
